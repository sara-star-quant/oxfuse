# 0005: `f32` is the only element type

Date: 2026-10-20. Status: accepted.

## Context

Version one has no op that needs integers or another float width. Shape values are attributes, never tensor data.

## Decision

Every tensor is `f32`. The JSON `dtype` field exists and accepts only `"f32"`.

## Consequences

- Kernels, the oracle and the bit-identity contract between backends are all stated for one type.
- Adding a type means extending `DType`, the shape and kernel rules, and the oracle together. The `dtype` field is already in the format, so files do not change shape.
- Alternatives considered: an `i64` type for shapes (rejected: nothing consumes it).
