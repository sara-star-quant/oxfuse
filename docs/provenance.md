# Provenance ledger

Where each algorithm comes from and under what terms. The rule: implement from specifications and published papers, write the code here, and copy no line of another project's source. `cargo test -p oxfuse --test provenance` fails when a function of the math and kernel files (listed in the test) has no row here, or a row names a function that does not exist.

## Dependencies and tools

| Name | Used for | Licence | Ships in the crates |
|---|---|---|---|
| `fearless_simd` 1.1 | SIMD vectors and run time dispatch | Apache-2.0 OR MIT | yes |
| `rayon` | thread split under the `parallel` feature | MIT OR Apache-2.0 | yes, optional |
| `wgpu` 30 and `pollster` | the GPU backend | MIT OR Apache-2.0 | yes, optional |
| `core-math` 1.4 | correctly rounded `exp` as a test oracle (`scripts/exp-oracle`, outside the workspace) | MIT | no |
| `proptest`, `criterion` | tests and benchmarks | MIT OR Apache-2.0 | no |

Licences are those in each crate's metadata, checked with `cargo metadata` on 2026-10-24. `cargo deny check` enforces the allow-list in `deny.toml` on every pull request.

## Not used

No code, tables or constants from GPL or LGPL projects, from projects without a stated licence, or from closed sources; no vendor or contrib operators (the importer rejects every domain but `ai.onnx`). Statements about other projects appear only with a source and a date, in [comparison.md](comparison.md).
